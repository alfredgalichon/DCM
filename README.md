# Discrete Choice Models — Open Companion Materials

The repository provides a tested computational companion to Alfred Galichon’s book *Discrete Choice Models*, published by Princeton University Press (2026), including Python code, simulations, empirical examples, notebooks, and teaching slides.

## Contents

- `dcm-slides.pdf`: a comprehensive slide deck covering the main topics of the book;
- `code/`: Python implementations, simulations and empirical examples;
- `docs/`: HTML notebooks on discrete-choice estimation, matching, gravity models, dynamic programming and related topics.

These materials are intended to facilitate teaching, experimentation, computational reproducibility and the dissemination of the methods developed in and around the EQUIPRICE research project.
